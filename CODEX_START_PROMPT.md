# Стартовый запрос для Codex

Ты работаешь в репозитории Kulagina Telegram Assistant. Сначала внимательно прочитай `AGENTS.md`, `README.md`, `docs/REQUIREMENTS.md` и `docs/TEST_PLAN.md`.

Задача первого этапа — только аудит, никаких изменений production:
1. Сравни `src/archive/telegram_assistant_v1_4_3_reference.gs` и `src/telegram_assistant_v2_0_2_candidate.gs`.
2. Составь таблицу изменений по функциям и схемам Google Sheets.
3. Проверь код на ошибки авторизации, дубликаты, потерю/зацикливание Telegram updates, небезопасные операции с Drive, ошибки дат и календарные конфликты.
4. Отдельно установи, какие новые функции действительно реализованы, частично реализованы или отсутствуют: расписание НВГУ, консультации, повторяющиеся поручения, рассылки, справочник/пасхалки, общий реестр задач.
5. Запусти доступные локальные проверки. Не заявляй, что Apps Script/Telegram/Google Calendar работают, если не запускал интеграционные тесты в реальной тестовой среде.
6. Не угадывай HTML-разметку расписания и не используй настоящие секреты. Предложи тестовые адаптеры/моки.
7. Сохрани отчёт в `docs/AUDIT_REPORT.md` и предложи приоритетный план небольших исправлений с тестами.

Не переписывай проект целиком и не меняй рабочий бот. После аудита дождись следующего задания.
