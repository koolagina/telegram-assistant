# Сравнение скачанного Apps Script с репозиторием — 29.10.2026

Изучены две пользовательские копии после clasp pull: основной `Код.js` и `appsscript.json`. Это текущий исходный код проекта по переданному снимку, **не доказательство версии активного deployment**. Исходники/встроенный ID таблицы не перенесены в Git. Значения Script Properties/данные Sheets/Calendar/реальные triggers не читались. Код не загружался на сервер, функции реального бота не запускались.

## Основной результат

`Код.js`:445строк/37top-level функций, заголовок1.4. С архивом `src/archive/telegram_assistant_v1_4_3_reference.gs` совпадают36из37блоков функций. Отличаются только заголовок версии и `processCallback_`: в архиве подтверждение callback best-effort с try/catch, а скачанный файл вызывает answerCallbackQuery без защиты. Поэтому скачанную копию нельзя объявить точной копией архива1.4.3.

Кандидат `src/telegram_assistant_v2_0_5_candidate.gs`:1360строк/117функций; все37имён скачанного файла присутствуют,80новых.17общих блоков идентичны,20изменены. Это существенно более широкий переход, чем подключение clasp или замена вспомогательного экспорта. Новые функции в GitHub не следует представлять как работающие в реальном боте.
